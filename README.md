# 慢性失眠臨床導航

繁體中文成人慢性失眠互動決策輔助：從症狀、病程與睡眠機會入手，協助鑑別診斷、選擇 CBT-I 或與醫師討論藥物，並以日誌、ISI、白天功能及不良反應追蹤。這是教學與臨床輔助工具，尚未經臨床效能驗證，不是經驗證的數位 CBT-I 療程，也不自動開立處方。

網站：https://yht5582-source.github.io/insomnia-navigator/

## 使用流程

1. **初診評估**：輸入年齡、病程、每週受困擾夜數、主要症狀、睡眠機會、白天影響、ISI 基線與治療偏好，逐項確認共病及風險。
2. **診斷與治療**：核對慢性失眠核心條件，呈現 OSA、不寧腿、節律、精神與身體共病的鑑別方向。急性精神症狀或身體不穩定優先處理；未滿 18 歲不提供成人治療分支。
3. **睡眠日誌**：起床後填寫，以起床日期為準。記錄準備入睡及最終離床時間、入睡前清醒、夜間清醒、早醒後清醒、午睡與白天功能。支援編輯與刪除。
4. **追蹤評估**：輸入正式 ISI 總分、療程週數、策略落實天數、功能與副作用，產生趨勢及需重新評估的理由。

5. **病例示範**：12 例虛構病例，可依分類篩選，各附學習重點與預期分支。原有 6 例（典型、疑似 OSA、躁期、輪班與機會不足、透析與不寧腿、Z-drug 複雜睡眠行為），v1.2 新增 6 例：孕期睡眠維持困難、年長者早醒合併憂鬱與跌倒、喪親後短期失眠、晚睡晚起（DSWPD 鑑別）、慢性疼痛使用 opioid 且已完成 CBT-I、CBT-I 第 8 週未達反應（含日誌與三次追蹤）。載入會先確認是否取代現有個案。
6. **測驗**：20 題（基礎 8、進階 6、高階 6），高階含睡眠效率加權、睡眠時段草案計算與臨床整合題。作答即顯示解析與來源；選項順序每次隨機。
7. **心智圖**：8 大主題、48 個重點（診斷核心、急迫優先、鑑別、CBT-I、藥物、禁忌與安全、日誌、追蹤），支援關鍵字搜尋與回想模式。

## ISI 七項評分（v1.1）

初診與追蹤都提供「使用 ISI 七項評分」入口。依過去兩週狀況，配合正式 ISI 問卷登錄七項 0–4 分：入睡、睡眠維持、早醒、滿意程度、日常功能、他人察覺影響及擔心／困擾。項目以短標籤作計分提示，不宣稱為另行驗證的量表譯本；保留正式中文問卷來源與原作者資訊。

- 滿意程度由 0（非常滿意）至 4（非常不滿意）；不能反向計錯。
- 未完成七項時不顯示加總，也不允許把部分作答作為正式結果儲存。
- 七項填完自動帶入初診或追蹤總分，顯示 0–7、8–14、15–21、22–28 分層。
- 支援單項分數的備份與還原，匯入時核對單項加總與總分一致。
- 可直接登錄既有總分；手動輸入會清除該次單項紀錄，避免兩套結果互相衝突。
- 有追蹤紀錄後，初診基線與單項評分一起鎖定。
- 沿用既有 ISI 療效趨勢、反應／緩解判讀，且兼容舊版僅總分的備份。

## 診斷與治療邊界

- 核心條件：夜間睡眠困難、每週至少 3 夜、病程至少 3 個月、足夠睡眠機會與環境，以及白天功能受損或顯著困擾；需訪談及鑑別確認。ISI 不能單獨診斷。
- CBT-I 是治療核心。睡眠衛教僅為輔助；工具內的文字與日誌不能取代完整療程。
- 藥物按症狀及已知風險提供討論類別，包含低劑量 doxepin、DORA、Z-drug；排除猝睡症、複雜睡眠行為史等相關禁忌。孕哺、肝腎病、跌倒、opioid／酒精、疑似 OSA 或交互作用等需安全審查。未提供自動劑量與固定減藥比例。
- 長期 BZD／Z-drug 不可自行突然停用。若與 Z-drug 相關的複雜睡眠行為發生，停止相關藥物並立即聯絡醫師。
- 台灣適應症、劑型供應與健保給付需另查，國外指引列入不代表台灣已核准或給付。

## 睡眠計算與追蹤

- 夜間總睡眠分鐘 = 主要睡眠時段分鐘 − 入睡前清醒 − 夜間清醒 − 早醒後清醒。
- 睡眠效率 = 各夜總睡眠分鐘合計 ÷ 各夜主要睡眠時段分鐘合計 ×100%；午睡不列入。
- 支援跨午夜；資料不合理時拒絕計算。摘要使用最近 7 筆；睡眠時段討論草案需最近連續 7 個不同日期。
- 睡眠時段草案以平均總睡眠向上取整至 15 分鐘，保留 6–9 小時機會；這是本工具保守設計，非所有指引的統一門檻。平均睡眠少於 5 小時、嗜睡、OSA 線索、未控制癲癇、雙相病史、孕哺或跌倒等不自動計算。
- 常用研究指標：ISI 下降 ≥8 分為反應、ISI <8 為緩解。日間功能與副作用必須一起評估；不以分數直接決定加藥或停藥。
- 1–2 週、4–8 週及穩定後 1–3 個月為實務追蹤安排，可依病況調整；沒有推播、自動提醒或雲端追蹤服務。

## 資料與隱私

預設只在分頁記憶體保存。可明確選擇保存於瀏覽器 localStorage；無病人識別欄位、無後端資料庫、無分析追蹤程式，也不傳送表單資料。共用電腦不宜開啟持續保存。

可匯出／匯入 JSON 備份、匯出 UTF-8 CSV 日誌，以及列印／另存 PDF 摘要。匯入會檢查格式、數值、日期與重複紀錄；健康資訊備份需妥善保存。瀏覽器保存不等同正式病歷系統或資料備援。

## 開發與部署

無外部套件、CDN 或字型依賴；`index.html` 是整合 CSS 與 JavaScript 的單檔，可直接用瀏覽器開啟，亦可部署 GitHub Pages。

```sh
python3 build.py
./run-tests.sh   # 有 node 用 node；否則用 macOS 內建 jsc
python3 -m http.server 8765
```

原始碼：`template.html`、`style.css`、`engine.js`、`content.js`、`app.js`；建置輸出為根目錄及 `dist/` 的 `index.html`。變更後必須重新建置。測試涵蓋診斷邊界、OSA 與高風險分支、用藥排除、跨午夜、效率、日誌連續性、追蹤門檻與匯入驗證。

GitHub Pages 使用 `main` 分支根目錄；`.nojekyll` 停用 Jekyll。不需建置伺服器或機密金鑰。
